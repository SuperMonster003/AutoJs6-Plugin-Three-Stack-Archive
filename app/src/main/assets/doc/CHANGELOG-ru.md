# Примечания к выпуску

## v2.6.0

_2026/08/27_

- `Примечание` Для этой версии требуется соответствующая сборка AutoJs6 6.8.0 с Explorer Action v13 (код версии 5276 или новее)
- `Добавлено` На нативной странице архива теперь можно выбрать кодировку имен ZIP в строке пути без перехода на страницу управления; после смены сохраняются текущая внутренняя папка и существующие выбранные элементы
- `Добавлено` Explorer Action v13 повторно индексирует подготовленный источник в том же сеансе только для чтения и использует стабильные ID для восстановления самого глубокого доступного пути и существующих элементов
- `Улучшено` Новый индекс публикуется только после полной готовности; неверный выбор, ошибка сканирования, активный просмотр или извлечение сохраняют прежний индекс, а введенный пароль остается только в очищаемой памяти

## v2.5.0

_2026/08/27_

- `Примечание` Для этой версии требуется соответствующая сборка AutoJs6 6.8.0 с Explorer Action v12 (код версии 5276 или новее)
- `Добавлено` Полные стандартные наборы `.z01 + .zip` и современные наборы WinRAR `partN.rar` теперь можно просматривать и извлекать на нативной странице; многотомные архивы остаются только для чтения
- `Добавлено` Explorer Action v12 передает только ограниченный каталог соседних томов, одобренных хостом, и открывает каждый по непрозрачному ID как дескриптор только для чтения, не раскрывая каталог или системный путь
- `Исправлено` Метаданные каталога последнего тома разделенного ZIP корректно принимаются на Android 7 и новее, а данные читаются из всех разрешенных томов без ложного сообщения о повреждении последнего тома
- `Исправлено` CRC сегмента RAR больше не сравнивается с восстановленными данными; отсутствующие или изменившиеся после открытия тома дают стабильные типизированные ошибки
- `Улучшено` Количество, имена, ID и число открытий томов, UID вызывающей стороны, идентичность файлов и срок жизни сессии ограничены и повторно проверяются; прерванное копирование удаляет все фрагменты приватного кэша

## v2.4.0

_2026/08/26_

- `Примечание` Для этой версии требуется AutoJs6 6.8.0 с Explorer Action v11, код версии 5276 или новее
- `Добавлено` Архивы RAR4/RAR5 теперь можно просматривать, предварительно открывать и извлекать, включая шифрование содержимого и заголовков; RAR намеренно остается только для чтения
- `Добавлено` Нативная страница архива AutoJs6 может запросить пароль при первом открытии или во время извлечения и повторить операцию без потери пути или выбора
- `Исправлено` Первый том разделенного RAR сохраняет читаемые метаданные, но больше не предлагает извлечение, если соседние тома недоступны
- `Исправлено` После неверного пароля прежний ввод очищается, а повтор выполняется для неизмененного снимка без выхода из нативной страницы
- `Улучшено` RAR по возможности читает seekable-дескриптор хоста напрямую, не добавляет нативных ABI и использует общие проверки безопасности
- `Зависимость` Добавлены Junrar 8.1.0 и SLF4J 2.0.17 для RAR только для чтения на условиях вложенных лицензий

## v2.3.0

_2026/08/26_

- `Примечание` Для этой версии требуется совместимая сборка AutoJs6 6.8.0 с Explorer Action v10 (код версии 5276 или новее)

- `Добавлено` Нативное извлечение пишет в дерево вывода, принадлежащее хосту, показывает ход задачи, поддерживает отмену, безопасную нумерацию конфликтов и автоматическое обновление Explorer
- `Исправлено` Выход из архива на Android 7 больше не вызывает сбой во время очистки кэша предпросмотра хостом
- `Исправлено` Подписи на панели выбора с пятью действиями центрируются под значками на узких экранах
- `Улучшено` Режим выбора в архиве теперь показывает только Выход и Извлечь, скрывая операции файловой системы, неприменимые внутри архива

## v2.2.0

_2026/08/26_

- `Примечание` Для этого выпуска требуется соответствующая сборка AutoJs6 6.8.0 с Explorer Action v9 (код версии 5276 или новее)
- `Добавлено` Команда «Извлечь в...» теперь рекомендует текущую папку и создаёт одноимённую выходную папку через принадлежащую хосту транзакцию каталога; эквивалентное существующее имя безопасно нумеруется без изменения его содержимого
- `Добавлено` Управление обычным однотомным ZIP может импортировать целую папку через системный выбор Android, включая вложенные файлы и пустые папки
- `Исправлено` Выбор папки извлечения остаётся полностью доступным на узких и низких экранах и показывает точный путь по умолчанию
- `Исправлено` Отменённое, неудачное, прерванное или исчерпавшее место извлечение в ту же папку откатывает неопубликованный вывод; следующий сеанс восстанавливает прерванные транзакции хоста без изменения исходного архива
- `Улучшено` Explorer Action v9 атомарно публикует проверенные деревья каталогов и сразу после фиксации обновляет новую выходную папку в AutoJs6

## v2.1.0

_2026/08/25_

- `Примечание` Сейчас редактируются только обычные однотомные файлы `.zip`. JAR/AAR/WAR, многотомные ZIP, 7Z и семейство TAR остаются доступными только для чтения; при перестроении нормализуются комментарии, необязательные extra metadata и атрибуты разрешений Unix
- `Добавлено` Управление архивом... открывает выбранный ZIP на странице управления с действиями Добавить файлы..., Новая папка..., Переименовать... и Удалить, включая переименование и удаление поддеревьев каталогов
- `Добавлено` Explorer Action v8 перестраивает архив в ожидающем выводе хоста, полностью перечитывает результат, атомарно заменяет оригинал только после проверки и автоматически обновляет строку Explorer
- `Улучшено` Каждое изменение предварительно проверяется как неизменяемый план на опасные пути, повторяющиеся или эквивалентные имена, конфликты файлов и папок, неподдерживаемые сохраняемые элементы и изменения источника до фиксации замены
- `Улучшено` Перестроение ZIP сохраняет содержимое Stored/Deflate, доступные временные метки и поддерживаемое шифрование ZipCrypto/AES; отмена или ошибка проверки прерывает ожидающий вывод и оставляет исходный архив неизменным

- `Добавлено` Explorer Action v6 открывает поддерживаемые элементы во встроенных средствах просмотра документов, изображений, аудио и видео
- `Добавлено` Действие «Извлечь в...» для выбора папки и извлечения всего архива
- `Добавлено` Действие «Управление архивом...» открывает страницу управления с диапазонами извлечения всего архива, текущей внутренней папки и отмеченных элементов, сохраняя быстрое извлечение всего архива
- `Добавлено` Политики конфликтов при извлечении: запрос, пропуск, перезапись и автоматическое переименование, с применением ко всем, точными итогами и сохранением существующих папок вывода
- `Добавлено` Explorer Action v4 добавляет «Сжать...» в меню обычных файлов и папок и на панель из пяти действий для выбора с общей родительской папкой
- `Добавлено` Создание ZIP с именем по умолчанию, уровнями сжатия, прогрессом, отменой и автоматической нумерацией конфликтов
- `Добавлено` Создание стандартных многотомных ZIP, включая AES-256, с готовым размером в МиБ или пользовательским целым значением; весь набор получает единое безопасное базовое имя, а завершающий `.zip` появляется после нумерованных томов
- `Добавлено` Создание отдельного архива для каждого элемента выбора с общей родительской папкой, с предварительным списком выходов, автоматической нумерацией конфликтов и явным сохранением и отчётом о готовых выходах после последующего сбоя или отмены
- `Добавлено` Создание не-solid 7Z с уровнями от 0 до 9 и необязательным шифрованием содержимого AES-256; имена остаются видимыми, а шифрование имён не заявляется ошибочно
- `Добавлено` Создание TAR, TAR.GZ, TAR.XZ, TAR.BZ2 и TAR.ZST с уровнями по формату и полной заменой составного расширения
- `Добавлено` Просмотр и извлечение ZIP с шифрованием ZipCrypto/AES, повторный ввод неверного пароля на месте и необязательное создание ZIP с AES-256, где имена файлов остаются видимыми и требуется совпадающее подтверждение пароля
- `Добавлено` Просмотр, предпросмотр и извлечение обычных или solid-архивов 7Z с распространёнными цепочками сжатия и фильтров, AES-шифрованием содержимого и заголовка; отсутствие или ошибка пароля получают явную диагностику
- `Добавлено` Просмотр, предпросмотр и извлечение несжатых TAR в нативном списке с проверкой контрольной суммы заголовков; ссылки, узлы устройств и разреженные элементы остаются только для просмотра
- `Добавлено` Просмотр, предпросмотр и извлечение TAR.GZ/TGZ, TAR.XZ/TXZ, TAR.BZ2/TBZ2 и TAR.ZST/TZST через те же нативные пути; определение формата проверяет сигнатуру компрессора и внутреннюю структуру TAR
- `Добавлено` Совместимый, строгий и пользовательский бюджеты извлечения; архивы вне бюджета доступны для просмотра только для чтения и перед записью показывают расчетный вывод, превышенные параметры и однократное подтверждение
- `Добавлено` Прогресс извлечения показывает элементы, байты, текущий элемент, скорость и расчетное оставшееся время и поддерживает надежную отмену
- `Исправлено` Список ZIP теперь строится по метаданным и поддерживает префиксы SFX, старые кодировки, разделители Windows и больше читаемых методов
- `Исправлено` Стандартные многотомные ZIP `.z01 + .zip` теперь перечисляют требуемые предыдущие тома вместо сообщения о повреждении последнего тома
- `Исправлено` Кодировку имён ZIP можно выбрать вручную при ошибке автоопределения, и извлечение использует тот же выбор
- `Исправлено` Неизвестный размер, корректные URI DocumentsProvider и дополнительные права записи больше не блокируют допустимый архив
- `Исправлено` Исправлены просмотр и распаковка ZIP в Android 7.x, ранее вызывавшие API только новых версий системы
- `Исправлено` ZIP с именами Unicode теперь корректно открываются на Android 7, даже если флаг имени UTF-8 отсутствует или обрабатывается бэкендом непоследовательно
- `Исправлено` Неверные пароли теперь стабильно классифицируются как PASSWORD/WRONG_PASSWORD, а элементы AES v2 с нулевым сохранённым CRC больше не считаются повреждёнными по ошибке
- `Исправлено` Имя папки извлечения для составных расширений TAR.GZ, TAR.XZ, TAR.BZ2 и TAR.ZST теперь удаляет весь суффикс и больше не сохраняет `.tar`
- `Исправлено` Архивы с переходами к родительскому каталогу, абсолютными путями, префиксами дисков или управляющими символами в именах остаются доступными для просмотра; опасные имена помещаются в изолированную папку только для чтения, допускают предпросмотр читаемых данных и требуют явного пропуска перед извлечением
- `Исправлено` Извлечение больше не перезаписывает существующие файлы или папки, если поставщик назначения считает одинаковыми имена, различающиеся регистром или эквивалентные в Unicode; эквивалентные имена выходных папок автоматически нумеруются
- `Исправлено` При отмене или сбое новый корень вывода откатывается в неотменяемой фазе очистки; если поставщик отказывает в удалении, вместо одного общего сообщения указываются имя и URI возможного остатка
- `Исправлено` Создание зашифрованных 7Z теперь работает на Android 7, а проверка сопоставляет элементы по путям и не считает допустимое различие порядка в бэкенде ошибкой
- `Исправлено` Страница управления теперь адаптируется к невысоким экранам в книжной и альбомной ориентации: архив и путь перенесены в панель, настройки доступны в компактной горизонтальной строке, а элементы и действия остаются видимыми при масштабе шрифта до 2,0x
- `Улучшено` Удалены фиксированный предел 4 ГиБ и пороги размера/коэффициента при просмотре с сохранением изоляции и проверки целостности
- `Улучшено` Добавлен проверяемый Roadmap, README и CHANGELOG переписаны
- `Улучшено` Отдельный экран следует системной теме и динамическим цветам Material
- `Улучшено` ZIP, 7Z и форматы TAR записываются через привязанный к UID сеанс хоста во временный файл той же папки и атомарно фиксируются без разрешения хранилища и перезаписи
- `Улучшено` Возможности формата и элементов единообразно проверяются для предпросмотра, извлечения и создания, поэтому недоступные параметры остаются отключёнными
- `Улучшено` При сбое отображаются формат, этап, стабильный код и причина; отладочная сборка позволяет скопировать полную диагностику
- `Улучшено` Обычные архивы теперь открываются через каналы с независимой позицией поверх дескриптора хоста только для чтения без полного копирования; несовместимые источники или читатели (сейчас включая зашифрованные ZIP) используют закрытый кэш, очищаемый при закрытии, ошибке или истечении срока
- `Улучшено` Унифицированы транзакции вывода при создании ZIP, 7Z и форматов TAR; нечитаемые источники и ошибки резервирования, открытия, записи или фиксации получают стабильные этапы, а неподтверждённая отмена закрывает сеанс, показывает планируемый путь и блокирует небезопасный повтор
- `Улучшено` Перед открытием временного вывода источники сканируются; форма отдельно показывает сканирование, сжатие, проверку и фиксацию, общее число файлов, прочитанные байты и файлы с неизвестным размером
- `Улучшено` Созданные архивы полностью перечитываются до публикации с проверкой формата, элементов, размеров, CRC и отпечатков содержимого; каждый ожидающий том ZIP также сравнивается побайтно
- `Зависимость` Добавлена Zip4j 2.11.5 под Apache License 2.0 для зашифрованных потоков ZIP, создания AES-256 и пути совместимости с Android 7.x
- `Зависимость` Добавлена XZ for Java 1.12 под лицензией 0BSD для чтения и записи TAR.XZ/TXZ на чистой Java без нативных ABI
- `Зависимость` Добавлена zstd-jni 1.5.7-15 под лицензией BSD для чтения и записи TAR.ZST/TZST; все четыре Android ABI прошли проверки выравнивания ELF 16 КиБ и RELRO
