# リリースノート

## v2.9.0

_2026/08/27_

- `注記` このリリースには Explorer Action v16 を備えた対応 AutoJs6 6.8.0 ビルド (バージョンコード 5276 以降) が必要です
- `追加` 圧縮フォームに既定でオフの圧縮後に元項目をゴミ箱へ移動を追加し、全物理出力の検証とコミットが完了した後だけ実行します
- `追加` Explorer Action v16 は元の完全な選択順とコミット済みの全出力トランザクションだけを受け付け、ホストが元項目と出力の同一性を再検証してからゴミ箱を使用します
- `修正` ホストは元項目を除去する前に復旧コピーを同期してゴミ箱記録を永続化します。ディレクトリが一部しか除去できない場合も、唯一の復旧データを消さず復旧可能なコピーを保持します
- `改善` ゴミ箱フェーズはキャンセル不可で、完了、復旧が必要、失敗、結果不明を個別に表示します。Binder 応答を失った場合は盲目的に再試行せずホストの終端状態を照会します

## v2.8.0

_2026/08/27_

- `注記` このリリースには Explorer Action v15 を備えた対応 AutoJs6 6.8.0 ビルド (バージョンコード 5276 以降) が必要です
- `追加` 標準分割 ZIP と項目ごとの個別圧縮は、全出力の書き込みと読み戻し検証を完了してから Explorer Action v15 の単一の復旧可能バッチとして公開されます
- `修正` 複数出力の作成は通常の失敗経路で確定済みの部分結果を残さなくなり、バッチ全体の確定後にだけ Explorer を更新して成功を報告します

- `改善` ホストは公開前に親フォルダーと各一時ファイルの同一性を永続記録し、失敗や再起動では一致するメンバーだけを巻き戻します。外部変更されたファイルは保持して手動復旧を報告します

## v2.7.0

_2026/08/27_

- `注記` このリリースには Explorer Action v14 を備えた対応 AutoJs6 6.8.0 ビルド (バージョンコード 5276 以降) が必要です
- `追加` 完全な連番 `.zip.001` と `.7z.001` セットを `.001` ボリュームから閲覧、プレビュー、展開できるようになりました。連番セットは読み取り専用です
- `追加` Explorer Action v14 は上限付き複合ファイル名サフィックス照合を追加し、UID に固定された v12 兄弟ボリュームソースを再利用します。任意の `.001` ファイルには一致しません

- `改善` 兄弟ボリューム番号は `.002` から `.128` に制限され、存在する全ボリュームは連続している必要があります。reader は次に欠けたボリュームを正確に報告し、具体化の前後で同一性を再検証し、内部編集機能を公開しません

- `追加` 同じ親フォルダー内の複数選択から項目ごとにアーカイブを作成し、出力プレビュー、自動競合番号付け、後続の失敗やキャンセル時の完了済み出力の明示的な保持と報告に対応
- `追加` レベル 0 から 9 と任意の AES-256 内容暗号化に対応した非 solid 7Z 作成；ファイル名は表示されたままで、ファイル名暗号化を誤って通知しません
- `追加` 形式ごとのレベルと複合拡張子全体の更新に対応した TAR、TAR.GZ、TAR.XZ、TAR.BZ2、TAR.ZST 作成
- `追加` ZipCrypto/AES 暗号化 ZIP の参照と展開、誤ったパスワードのその場での再入力、および一致するパスワード確認付きでファイル名を表示したままの任意の AES-256 ZIP 作成に対応
- `追加` 通常または solid の 7Z を一般的な圧縮/フィルターチェーン、AES 内容暗号化、ヘッダー暗号化込みで参照、プレビュー、展開；パスワード不足または誤りを明確に診断

- `追加` 同じホストのネイティブ経路で TAR.GZ/TGZ、TAR.XZ/TXZ、TAR.BZ2/TBZ2、TAR.ZST/TZST の参照、プレビュー、展開に対応；形式検出で圧縮ストリームの署名と内部 TAR 構造を検証
- `追加` 互換、厳格、カスタムの展開リソース予算。予算超過時も読み取り専用で参照でき、書き出し前に推定出力、超過項目、1 回限りの確認を表示
- `追加` 展開中に項目数、バイト数、現在の項目、転送速度、推定残り時間を表示し、確実なキャンセルに対応
- `修正` ZIP 一覧をメタデータ方式に変更し、自己展開形式の前置データ、旧式の名前エンコーディング、Windows 区切り文字、追加の読取可能メソッドに対応
- `修正` 標準の分割 ZIP `.z01 + .zip` で、最終ボリュームを破損扱いせず、必要な前方ボリューム名を表示
- `修正` ZIP ファイル名の自動検出が正しくない場合に手動で上書きし、展開でも同じエンコーディングを再利用
- `修正` 不明なサイズ、有効な DocumentsProvider URI、ホストの追加書込権限で有効なアーカイブが拒否される問題を修正
- `修正` 新しいシステム専用 API の呼び出しにより Android 7.x で ZIP を参照・展開できない問題を修正

- `修正` TAR.GZ、TAR.XZ、TAR.BZ2、TAR.ZST などの複合拡張子で、既定の展開先フォルダー名から完全な接尾辞を除去し、`.tar` が残る問題を修正

- `修正` キャンセルまたは展開失敗時はキャンセル不可のクリーンアップ段階で新規出力ルートをロールバック；プロバイダーが削除を拒否した場合は一般的なエラーだけでなく、残存する可能性のある名前と URI を表示
- `修正` Android 7 で暗号化 7Z を作成できない問題を修正し、検証項目をパスで照合してバックエンドの正当な順序差による誤判定を防止
- `修正` 管理ページを縦向き・横向きの高さが短い画面に最適化；書庫とパス情報をツールバーへ移し、設定をコンパクトな横スクロール行に残すことで、最大 2.0 倍のフォントでも項目と操作を表示
- `改善` 固定 4 GiB 上限と参照時のサイズ/圧縮率制限を削除し、パス隔離と整合性検証は維持
- `改善` チェック可能な Roadmap を追加し README と CHANGELOG を全面更新
- `改善` 独立画面がシステムの昼夜モードと Material 動的色に追従
- `改善` ZIP、7Z、TAR 系出力をプラグイン UID に固定したホストセッションで同じフォルダーの一時ファイルへ書き込み、ストレージ権限や上書きなしでアトミックに確定

- `改善` 失敗時に形式、処理段階、安定したコード、理由を表示し、デバッグ版では完全な診断情報をコピー可能
