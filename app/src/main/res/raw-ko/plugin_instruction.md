3-Stack Archive는 AutoJs6 파일 관리자에 압축 파일 기능을 더합니다. ZIP, 7Z, RAR, TAR 계열 압축 파일을 폴더처럼 탐색하고, 전체 또는 일부를 풀고, 파일과 폴더를 압축할 수 있습니다. 플러그인 홈 화면에서도 압축 파일을 단독으로 열어 탐색하고 풀 수 있습니다.

### 시작하기

1. "플러그인 센터"에서 3-Stack Archive를 활성화합니다.
2. AutoJs6 파일 관리자에서 압축 파일의 메뉴를 열고 "압축 파일 보기"를 선택합니다. 내용은 같은 파일 목록에 표시됩니다.
3. 폴더를 열거나 검색하거나, 항목을 탭해 AutoJs6 미리보기로 엽니다. 뒤로 키는 먼저 압축 파일 안의 상위 폴더로 돌아갑니다.
4. 파일을 꺼내려면 압축 파일의 메뉴에서 "압축 풀기..."를 선택해 전체를 풀거나, 항목을 길게 눌러 선택한 부분만 풉니다.

### 주요 기능

- **탐색과 미리보기**: ZIP, JAR, 7Z, RAR, TAR 계열 압축 파일을 AutoJs6 파일 목록에서 탐색하고, 검색하거나 경로 표시줄로 이동할 수 있습니다. 문서, 이미지, 오디오, 동영상은 풀지 않고 미리 볼 수 있습니다.
- **압축 파일로 열기**: 파일 이름이 인식되지 않으면 파일 메뉴에서 "압축 파일로 열기..."를 선택합니다. 형식은 내용으로 판별되어 경로 표시줄에 표시됩니다.
- **압축 풀기**: 압축 파일 전체, 현재 폴더 (경로 표시줄 오른쪽 버튼) 또는 선택한 항목을 풀 수 있으며 진행률 표시와 취소를 지원합니다. 같은 이름의 파일은 건너뛰기, 덮어쓰기, 자동 번호 붙이기 중에서 고릅니다.
- **비밀번호와 파일 이름 인코딩**: 암호화된 ZIP, 7Z, RAR은 열거나 풀 때 비밀번호를 묻고, 틀리면 바로 다시 입력할 수 있습니다. ZIP 파일 이름이 깨지면 경로 표시줄에서 인코딩을 바꿉니다.
- **분할 압축 파일**: 빠짐없는 `.z01` + `.zip`, `partN.rar`, `.zip.001`, `.7z.001` 분할 세트는 탐색, 미리보기, 압축 풀기가 가능하지만 수정할 수는 없습니다.
- **압축**: 파일, 폴더 또는 같은 폴더에서 여러 개 선택한 항목에 "압축..."을 선택해 ZIP, 7Z, TAR, TAR.GZ 등을 만듭니다. ZIP과 7Z는 비밀번호를 설정할 수 있고 ZIP은 크기별로 분할할 수 있습니다.
- **항목별 압축**: 여러 항목을 선택했을 때 "각 항목을 개별적으로 압축"을 켜면 항목마다 압축 파일을 하나씩 만듭니다. 이름이 겹치면 자동으로 번호를 붙입니다.
- **압축 파일 수정**: 일반 단일 볼륨 ZIP, 암호화되지 않은 비 solid 7Z, TAR 계열 압축 파일은 파일과 폴더 추가, 빈 폴더 만들기, 항목 이름 바꾸기와 삭제가 가능합니다. 수정 후에는 "이전 버전 복원"으로 한 번 되돌릴 수 있습니다.
- **원본을 휴지통으로**: 기본으로 꺼져 있는 "압축 후 원본 항목을 휴지통으로 이동"을 켜면 모든 출력을 검증한 뒤에만 원본 항목을 AutoJs6 휴지통으로 옮깁니다. 압축 화면 메뉴의 "원본 항목 복원 기록"에서 되돌릴 수 있습니다.
- **홈 화면**: 런처에서 플러그인을 열고 "압축 파일 열기"를 탭하면 압축 파일을 탐색하고 풀 수 있습니다. "설정"에서 언어, 다크 모드, 테마 색상, 런처 아이콘을 바꿀 수 있습니다.

### 스크립트에서 사용하기

플러그인 도구 `archive_list`, `archive_read`, `archive_extract`로 스크립트에서 압축 파일 내용을 나열하고, 안의 텍스트 파일을 읽고, 압축을 풀 수 있습니다:

```js
let list = plugins.tools.call('archive_list', { archive: './demo.zip' });
list.result.entries.forEach(e => console.log(e.path, e.size));

let readme = plugins.tools.call('archive_read', { archive: './demo.zip', path: 'README.md' });
console.log(readme.result.text);

let extracted = plugins.tools.call('archive_extract', { archive: './demo.zip' }, {
    outputs: { files: './out/demo' },
});
console.log(extracted.result.filesExtracted, extracted.result.kept);
```

- 상대 경로는 AutoJs6 작업 디렉터리를 기준으로 합니다. 압축을 풀 폴더는 이미 있어도 되며, 기존 파일은 그대로 남고 개수가 `kept`에 기록됩니다.
- `archive_read`는 UTF-8 텍스트를 호출당 최대 64 KiB 반환합니다. 바이너리 파일은 텍스트를 반환하지 않고 `binary`가 `true`가 됩니다.
- 암호화된 압축 파일의 비밀번호는 `password`로 전달합니다. 분할 압축 파일은 플러그인 도구로 처리할 수 없습니다.

### 요구 사항

- Android 7.0 이상.
- AutoJs6 6.8.0 이상이 필요하며 이 플러그인이 "플러그인 센터"에서 활성화되어 있어야 합니다. 플러그인 홈 화면은 AutoJs6 없이도 사용할 수 있습니다.
- 저장소나 네트워크 권한을 요청하지 않으며, AutoJs6 또는 시스템 파일 선택기에서 고른 파일만 처리합니다.

### 자주 묻는 질문

**메뉴에 플러그인 동작이 보이지 않는 경우**

이 플러그인이 "플러그인 센터"에서 활성화되어 있는지 확인하세요. 일부 AutoJs6 버전은 플러그인 동작을 플러그인 이름의 하위 메뉴 "3-Stack Archive"에 모아 둡니다. 이름이 인식되지 않는 압축 파일에는 "압축 파일로 열기..."를 사용하세요.

**압축 파일을 보기만 하고 수정할 수 없는 이유**

RAR, 분할 압축 파일, JAR/AAR/WAR, 암호화되었거나 solid인 7Z는 탐색과 압축 풀기만 가능합니다. "압축 파일 관리..."에서 현재 압축 파일의 형식과 읽기 전용인 이유를 볼 수 있습니다.

**암호화된 압축 파일의 파일 이름**

ZIP과 7Z 암호화는 파일 내용을 보호하며, 압축 파일 안의 파일 이름은 그대로 보입니다. 민감한 정보는 파일 이름에 넣지 마세요.

**분할 압축 파일이 열리지 않는 경우**

표준 분할 ZIP은 마지막 `.zip`에서, WinRAR 세트는 첫 번째 `partN.rar`에서, 번호가 붙은 세트는 `.001` 파일에서 엽니다. 모든 볼륨은 같은 폴더에 있어야 합니다.

플러그인 도구의 모든 매개변수와 반환값은 [AutoJs6 문서 > 플러그인](https://docs.autojs6.com/#/plugins)을, 기타 정보는 [프로젝트 페이지](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stack-Archive)를 참고하세요.
