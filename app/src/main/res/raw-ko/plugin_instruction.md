기본 파일 관리자에서 Archive Manager를 사용합니다:

1. `Archive Manager` 플러그인을 설치하고 활성화합니다.
2. 지원되는 압축 파일의 더보기 메뉴를 엽니다.
3. `압축 파일 열기`를 선택합니다.
4. 폴더를 탐색하거나 검색하고 경로 표시줄로 이동하거나 호스트 뷰어로 지원 항목을 엽니다.
5. 뒤로 가기는 일반 파일 목록으로 돌아가기 전에 압축 파일 내부의 상위 폴더로 이동합니다.

전체 압축 파일을 바로 풀려면 파일 메뉴에서 `압축 풀기...`를 선택한 뒤 출력 폴더를 지정합니다.

압축 파일을 만들려면 일반 파일 또는 폴더 메뉴에서 `압축...`을 선택합니다. 같은 폴더의 여러 항목을 선택한 뒤 하단 표시줄의 `압축...`을 사용할 수도 있습니다. 파일 이름, 형식 및 압축 수준을 선택합니다. ZIP과 7Z에는 선택적 비밀번호도 설정할 수 있습니다.

현재 버전은 ZIP 계열, 일반 또는 solid 7Z, TAR, TAR.GZ/TGZ, TAR.XZ/TXZ, TAR.BZ2/TBZ2 및 TAR.ZST/TZST를 읽고 풀 수 있습니다. 일반 또는 표준 분할 ZIP, 비 solid 7Z, TAR, TAR.GZ, TAR.XZ, TAR.BZ2 및 TAR.ZST를 만들 수 있으며 ZIP과 7Z에 선택적 비밀번호를 설정할 수 있지만 암호화 출력의 파일 이름은 계속 표시됩니다. TAR 링크, 장치 노드 및 희소 항목은 목록 전용입니다. 표준 `.z01 + .zip` 분할 ZIP의 마지막 볼륨만 열면 필요한 앞쪽 볼륨 이름을 표시하며 만들 때 프리셋 또는 사용자 지정 MiB 크기를 선택할 수 있습니다. 출력이 선택한 크기를 초과하면 분할되며, 더 작으면 하나의 `.zip` 파일로 유지됩니다. 기타 형식, 분할 볼륨 읽기, 항목별 압축 풀기 및 내부 편집은 프로젝트 Roadmap에 포함되어 있습니다.

플러그인은 저장소 전체 또는 네트워크 권한을 요청하지 않습니다. 일반 압축 파일은 호스트의 읽기 전용 디스크립터 위 독립 위치 채널에서 전체 복사 없이 직접 탐색합니다. 호환되지 않는 입력 또는 reader(현재 암호화 ZIP 포함)만 비공개 캐시로 대체하고 종료하거나 만료된 뒤 삭제합니다. 압축 파일 만들기는 플러그인에 고정된 단기 호스트 세션으로 읽고 현재 상위 폴더에만 트랜잭션 출력을 쓸 수 있습니다. 경로 순회, 원본 파일 크기 및 출력 경계 검사는 항상 유지됩니다.
