AutoJs6 기본 탐색기에서 압축 파일 탐색기를 사용합니다:

1. `Archive Browser` 플러그인을 설치하고 활성화합니다.
2. ZIP, JAR, AAR 또는 WAR 파일 하나의 더보기 메뉴를 엽니다.
3. `압축 파일 탐색`을 선택합니다.
4. 폴더를 탐색하거나 항목 경로를 검색한 뒤 파일 또는 폴더를 선택합니다.
5. `선택 항목 압축 풀기`를 선택하고 Android 시스템 선택기로 출력 폴더를 선택합니다.

플러그인은 입력 content URI에 대한 임시 읽기 전용 접근 권한을 받습니다. 저장소 또는 네트워크 권한을 요청하지 않으며 Storage Access Framework로 선택한 출력 트리에만 씁니다.

입력은 비공개 캐시에 임시 저장되며 최대 크기는 4 GiB입니다. 각 압축 파일은 항목 20,000개, 압축 해제된 단일 항목 512 MiB, 압축 해제된 전체 데이터 2 GiB, 압축 비율 1000:1로 제한됩니다. 안전하지 않은 경로와 지원되지 않는 압축 방식은 차단됩니다.
