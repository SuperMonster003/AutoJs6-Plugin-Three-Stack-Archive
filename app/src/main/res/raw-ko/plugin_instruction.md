기본 파일 관리자에서 압축 파일 관리자를 사용합니다:

1. `Archive Manager` 플러그인을 설치하고 활성화합니다.
2. ZIP, JAR, AAR, WAR 또는 TAR 파일 하나의 더보기 메뉴를 엽니다.
3. `압축 파일 열기`를 선택합니다.
4. 폴더를 탐색하거나 항목 경로를 검색한 뒤 파일 또는 폴더를 선택합니다.
5. `선택 항목 압축 풀기`를 선택하고 Android 시스템 선택기로 출력 폴더를 선택합니다.

전체 압축 파일을 바로 풀려면 파일 메뉴에서 `압축 풀기...`를 선택한 뒤 출력 폴더를 지정합니다.

ZIP을 만들려면 일반 파일 또는 폴더 메뉴에서 `압축...`을 선택합니다. 같은 폴더의 여러 항목을 선택한 뒤 하단 표시줄의 `압축...`을 사용할 수도 있습니다. 파일 이름과 압축 수준을 확인하면 현재 폴더에 생성됩니다.

현재 버전은 ZIP 계열 압축 파일과 비압축 TAR를 읽고 풀며 선택적 비밀번호가 있는 ZIP을 만들 수 있습니다. TAR 링크, 장치 노드 및 희소 항목은 목록 전용입니다. 압축 TAR 형식, 분할 및 내부 편집은 프로젝트 Roadmap에 포함되어 있습니다.

플러그인은 저장소 전체 또는 네트워크 권한을 요청하지 않습니다. 탐색 시 입력은 사용 가능한 공간에 따라 비공개 캐시에 임시 저장됩니다. ZIP 만들기는 플러그인에 고정된 단기 호스트 세션으로 읽고 현재 상위 폴더에만 트랜잭션 출력을 쓸 수 있습니다. 경로 순회 및 출력 경계 검사는 항상 유지됩니다.
