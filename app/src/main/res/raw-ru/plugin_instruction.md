3-Stack Archive добавляет работу с архивами в файловый менеджер AutoJs6: архивы ZIP, 7Z, RAR и семейства TAR можно просматривать как папки, извлекать целиком или частично, а файлы и папки - сжимать в архивы. Главный экран плагина также открывает архивы для просмотра и извлечения без AutoJs6.

### Начало работы

1. Включите 3-Stack Archive в разделе "Центр плагинов".
2. В файловом менеджере AutoJs6 откройте меню архива и выберите "Просмотр архива"; содержимое появится в том же списке файлов.
3. Открывайте папки, пользуйтесь поиском или нажмите на элемент, чтобы открыть его в средстве просмотра AutoJs6; кнопка возврата сначала поднимается на уровень выше внутри архива.
4. Чтобы извлечь файлы, выберите в меню архива пункт "Извлечь в..." для всего архива или выделите элементы долгим нажатием и извлеките только их.

### Основные возможности

- **Просмотр и предпросмотр**: Архивы ZIP, JAR, 7Z, RAR и семейства TAR открываются в списке файлов AutoJs6 с поиском и переходами по строке пути; документы, изображения, аудио и видео можно просмотреть без предварительного извлечения.
- **Открыть как архив**: Если имя файла не распознано, выберите в меню файла пункт "Открыть как архив..."; формат определяется по содержимому и отображается в строке пути.
- **Извлечение**: Можно извлечь весь архив, текущую папку (кнопка справа от строки пути) или выделенные элементы, с индикатором хода и отменой; файлы с совпадающими именами можно пропустить, перезаписать или пронумеровать автоматически.
- **Пароли и кодировка имён**: Зашифрованные ZIP, 7Z и RAR запрашивают пароль при открытии или извлечении, неверный пароль можно сразу ввести заново; нечитаемые имена файлов ZIP исправляются сменой кодировки в строке пути.
- **Многотомные архивы**: Полные наборы `.z01` + `.zip`, `partN.rar`, `.zip.001` и `.7z.001` можно просматривать, открывать в средстве просмотра и извлекать, но не изменять.
- **Сжатие**: Выберите "Сжать..." для файла, папки или нескольких элементов, выделенных в одной папке, чтобы создать ZIP, 7Z, TAR, TAR.GZ и другие архивы; для ZIP и 7Z можно задать пароль, а ZIP - разбить на тома по размеру.
- **Архив на каждый элемент**: При выделении нескольких элементов включите "Сжимать каждый элемент отдельно", чтобы создать отдельный архив для каждого; конфликты имён нумеруются автоматически.
- **Изменение архивов**: В обычные однотомные ZIP, незашифрованные не solid 7Z и архивы семейства TAR можно добавлять файлы и папки, создавать пустые папки, переименовывать и удалять элементы; после изменения пункт "Восстановить предыдущую версию" отменяет его один раз.
- **Исходные элементы в корзину**: Если включить параметр "Переместить исходные элементы в корзину после сжатия" (по умолчанию выключен), исходные элементы попадут в корзину AutoJs6 только после проверки всех выходных архивов; вернуть их можно через пункт "История восстановления исходных элементов" в меню страницы сжатия.
- **Главный экран**: Откройте плагин из лаунчера и нажмите "Открыть архив", чтобы просматривать и извлекать архивы; в разделе "Настройки" меняются язык, тёмный режим, цвет темы и значок лаунчера.

### Использование в скриптах

Инструменты плагина `archive_list`, `archive_read` и `archive_extract` выводят содержимое архива, читают текстовый файл внутри него и извлекают архив из скрипта:

```js
let list = plugins.tools.call('archive_list', { archive: './demo.zip' });
list.result.entries.forEach(e => console.log(e.path, e.size));

let readme = plugins.tools.call('archive_read', { archive: './demo.zip', path: 'README.md' });
console.log(readme.result.text);

let extracted = plugins.tools.call('archive_extract', { archive: './demo.zip' }, {
    outputs: { files: './out/demo' },
});
console.log(extracted.result.filesExtracted, extracted.result.kept);
```

- Относительные пути отсчитываются от рабочего каталога AutoJs6; папка для извлечения может уже существовать, имеющиеся в ней файлы остаются без изменений и учитываются в `kept`.
- `archive_read` возвращает текст UTF-8, не более 64 КиБ за вызов; для двоичного файла текст не возвращается, а `binary` равно `true`.
- Пароль зашифрованного архива передаётся в `password`; многотомные архивы инструменты плагина не обрабатывают.

### Требования

- Android 7.0 или новее.
- AutoJs6 6.8.0 или новее, а плагин должен быть включён в разделе "Центр плагинов"; главный экран плагина работает и без AutoJs6.
- Плагин не запрашивает разрешений на доступ к хранилищу и сети и обрабатывает только файлы, выбранные вами в AutoJs6 или в системном средстве выбора файлов.

### Частые вопросы

**Случаи, когда действий плагина нет в меню**

Убедитесь, что плагин включён в разделе "Центр плагинов". Некоторые версии AutoJs6 собирают действия плагинов в подменю с именем плагина, "3-Stack Archive"; для архива с нераспознанным именем используйте пункт "Открыть как архив...".

**Причины, по которым архив доступен только для чтения**

Архивы RAR, многотомные архивы, JAR/AAR/WAR, а также зашифрованные или solid-архивы 7Z можно только просматривать и извлекать. Пункт "Управление архивом..." показывает формат текущего архива и причину ограничения.

**Имена файлов в зашифрованных архивах**

Шифрование ZIP и 7Z защищает содержимое файлов, но их имена внутри архива остаются видимыми, поэтому не указывайте в именах файлов конфиденциальные сведения.

**Случаи, когда многотомный архив не открывается**

Стандартный многотомный ZIP открывайте с последнего файла `.zip`, набор WinRAR - с первого `partN.rar`, нумерованный набор - с файла `.001`; все тома должны лежать в одной папке.

Все параметры и результаты инструментов плагина описаны в [документации AutoJs6 > Плагины](https://docs.autojs6.com/#/plugins), остальные сведения - на [странице проекта](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stack-Archive).
