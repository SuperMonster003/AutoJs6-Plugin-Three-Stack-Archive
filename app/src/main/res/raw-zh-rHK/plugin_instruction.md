從主檔案管理器使用壓縮檔瀏覽器:

1. 安裝並啟用 `Archive Browser` 外掛程式.
2. 開啟一個 ZIP, JAR, AAR 或 WAR 檔案的更多選單.
3. 選取 `瀏覽壓縮檔`.
4. 瀏覽資料夾或搜尋項目路徑, 然後選取檔案或資料夾.
5. 選取 `解壓縮所選項目`, 再透過 Android 系統選取器指定輸出資料夾.

外掛程式只接收輸入 content URI 的臨時唯讀權限. 外掛程式不會要求儲存空間或網絡權限, 並且只會寫入透過 Storage Access Framework 選取的輸出目錄樹.

輸入會暫存到應用程式私人快取, 上限為 4 GiB. 每個壓縮檔最多包含 20,000 個項目, 單一項目解壓縮後最多 512 MiB, 解壓縮後總資料最多 2 GiB, 壓縮比率上限為 1000:1. 不安全路徑和不受支援的壓縮方法會被封鎖.
