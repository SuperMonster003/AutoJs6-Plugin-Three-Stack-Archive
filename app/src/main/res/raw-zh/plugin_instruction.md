从主文件管理器使用压缩档案管理器:

1. 安装并启用 `Archive Manager` 插件.
2. 打开一个受支持压缩档案文件的溢出菜单.
3. 选择 `打开压缩档案`.
4. 浏览文件夹、搜索、使用路径栏跳转, 或通过宿主预览器打开支持的条目.
5. 返回键会先回到档案内上一级, 再返回普通文件列表.

如需直接解压整个档案, 可从文件菜单选择 `解压到...`, 然后指定输出文件夹.

如需创建档案, 可从普通文件或文件夹的菜单选择 `压缩...`. 也可以先多选同一文件夹中的项目, 再使用底部操作栏的 `压缩...`. 请选择文件名、格式和压缩级别; ZIP 与 7Z 还可以设置可选密码.

当前版本可以读取和解压 ZIP 系列、普通或 solid 7Z、TAR、TAR.GZ/TGZ、TAR.XZ/TXZ、TAR.BZ2/TBZ2 与 TAR.ZST/TZST, 并可创建 ZIP、非 solid 7Z、TAR、TAR.GZ、TAR.XZ、TAR.BZ2 与 TAR.ZST; ZIP 与 7Z 可使用可选密码, 加密输出的文件名仍然可见. TAR 链接、设备节点和稀疏项只读列出. 单独打开标准 `.z01 + .zip` 分卷 ZIP 的末卷时, 会列出所需的前序分卷. 更多格式、分卷读取和创建、按条目解压及档案内修改仍在项目 Roadmap 中.

插件不申请宽泛的存储或网络权限. 浏览时输入按实际可用空间暂存到应用私有缓存; 创建档案时通过绑定插件身份的短期宿主会话读取目标, 并且只能在当前父文件夹事务式写入输出. 路径穿越、源文件大小和输出边界检查始终保持启用.
