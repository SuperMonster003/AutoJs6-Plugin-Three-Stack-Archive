从主文件管理器使用 Archive Manager:

Archive Manager 2.22.0 需要 Android 7 或更高版本, 并需要配套的 AutoJs6 6.8.0 (versionCode 5276 或更高) 宿主公布 Explorer Action v21.

1. 安装并启用 `Archive Manager` 插件.
2. 打开一个受支持压缩档案文件的溢出菜单.
3. 选择 `打开压缩档案`.
4. 浏览文件夹、搜索、使用路径栏跳转, 或通过宿主预览器打开支持的条目.
5. 返回键会先回到档案内上一级, 再返回普通文件列表.

如需直接解压整个档案, 可从文件菜单选择 `解压到...`, 然后指定输出文件夹.

如需创建档案, 可从普通文件或文件夹的菜单选择 `压缩...`. 也可以先多选同一文件夹中的项目, 再使用底部操作栏的 `压缩...`. 请选择文件名、格式和压缩级别; ZIP 与 7Z 还可以设置可选密码.

当前版本可以读取和解压 ZIP 系列、普通或 solid 7Z、RAR4/RAR5、TAR、TAR.GZ/TGZ、TAR.XZ/TXZ、TAR.BZ2/TBZ2 与 TAR.ZST/TZST, 并可创建普通或标准分卷 ZIP、非 solid 7Z、TAR、TAR.GZ、TAR.XZ、TAR.BZ2 与 TAR.ZST; ZIP 与 7Z 可使用可选密码, 加密输出的文件名仍然可见. 普通单卷 ZIP、未加密且非 solid 并位于解码资源预算内的普通单卷 7Z，以及符合条件的 TAR 系列档案可通过完整校验重建添加、重命名和删除内容; RAR、加密、solid、分卷、危险路径、不支持方法或超预算的 7Z 与 TAR 特殊条目保持只读. 完整的标准 `.z01 + .zip`、现代 `partN.rar`、编号 `.zip.001` 与编号 `.7z.001` 卷组可通过宿主有界批准的同级描述符浏览和解压; 所有分卷输入都保持只读. 创建分卷 ZIP 时可选择预设或自定义 MiB 大小. 输出超过所选大小时才会分卷, 较小的输出仍为单个 `.zip`.

所有物理输出完成校验和提交后, 一个默认关闭的选项可以把完整源选择移入宿主回收站. Explorer Action v21 保留有界持久恢复历史; 恢复源项目始终保留已经创建的档案.

插件不申请宽泛的存储或网络权限. 普通档案通过宿主只读描述符上的独立位置读取通道直接浏览, 无需整份复制; 不兼容的输入或后端（当前包括加密 ZIP）按需回退到私有缓存, 并在关闭或过期后清理. 创建档案时通过绑定插件身份的短期宿主会话读取目标, 并且只能在当前父文件夹事务式写入输出. 路径穿越、源文件大小和输出边界检查始终保持启用.
