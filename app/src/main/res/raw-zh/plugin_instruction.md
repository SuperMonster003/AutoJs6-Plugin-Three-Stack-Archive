从主文件管理器使用压缩档案管理器:

1. 安装并启用 `Archive Manager` 插件.
2. 打开一个受支持压缩档案文件的溢出菜单.
3. 选择 `打开压缩档案`.
4. 浏览文件夹或搜索条目路径, 然后选择文件或文件夹.
5. 选择 `解压所选项`, 再通过 Android 系统选择器指定输出文件夹.

如需直接解压整个档案, 可从文件菜单选择 `解压到...`, 然后指定输出文件夹.

如需创建档案, 可从普通文件或文件夹的菜单选择 `压缩...`. 也可以先多选同一文件夹中的项目, 再使用底部操作栏的 `压缩...`. 请选择文件名、格式和压缩级别; 只有 ZIP 可以额外设置可选密码.

当前版本可以读取和解压 ZIP 系列、TAR、TAR.GZ/TGZ、TAR.XZ/TXZ、TAR.BZ2/TBZ2 与 TAR.ZST/TZST, 并可创建 ZIP、TAR、TAR.GZ、TAR.XZ、TAR.BZ2 与 TAR.ZST; 可选密码仅适用于 ZIP. TAR 链接、设备节点和稀疏项只读列出. 更多格式、分卷和档案内修改仍在项目 Roadmap 中.

插件不申请宽泛的存储或网络权限. 浏览时输入按实际可用空间暂存到应用私有缓存; 创建档案时通过绑定插件身份的短期宿主会话读取目标, 并且只能在当前父文件夹事务式写入输出. 路径穿越、源文件大小和输出边界检查始终保持启用.
