从主文件管理器使用压缩包浏览器:

1. 安装并启用 `Archive Browser` 插件.
2. 打开一个 ZIP, JAR, AAR 或 WAR 文件的溢出菜单.
3. 选择 `浏览压缩包`.
4. 浏览文件夹或搜索条目路径, 然后选择文件或文件夹.
5. 选择 `解压所选项`, 再通过 Android 系统选择器指定输出文件夹.

插件仅接收输入 content URI 的临时只读权限. 插件不申请存储或网络权限, 并且只会写入通过 Storage Access Framework 选择的输出目录树.

输入会暂存到应用私有缓存, 上限为 4 GiB. 每个压缩包最多包含 20,000 个条目, 单个条目解压后最多 512 MiB, 解压后总数据最多 2 GiB, 压缩比上限为 1000:1. 不安全路径和不受支持的压缩方法会被阻止.
