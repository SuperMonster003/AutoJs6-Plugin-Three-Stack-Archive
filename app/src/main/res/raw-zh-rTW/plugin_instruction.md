# AutoJs6 3-Stack Archive

獨立首頁可開啟壓縮檔案進行瀏覽與解壓縮, 建立及原位修改仍可從 AutoJs6 發起.
統一設定頁提供語言, 夜間模式, 主題色及四種啟動器圖示選項.
應用程式 ID 從 io.github.supermonster003.autojs6.plugin.archivemanager 改為 io.github.supermonster003.autojs6.plugin.three.stack.archive. Android 將其視為獨立應用程式, 原應用程式與資料可以保留, 設定不會自動遷移.


3-Stack Archive 2.22.0 需要 Android 7 或更新版本, 並需要配套的 AutoJs6 6.8.0 (versionCode 5276 或更高) 主程式公布 Explorer Action v21.

1. 安裝並啟用 `3-Stack Archive` 外掛程式.
2. 開啟一個受支援壓縮檔案的更多選單.
3. 選取 `開啟壓縮檔`.
4. 瀏覽資料夾、搜尋、使用路徑列跳轉, 或透過主程式預覽器開啟支援的項目.
5. 返回鍵會先回到壓縮檔內上一層, 再返回一般檔案清單.

若要直接解壓縮整個壓縮檔, 可從檔案選單選取 `解壓縮到...`, 然後指定輸出資料夾.

若要建立壓縮檔, 可從一般檔案或資料夾選單選取 `壓縮...`. 也可先多選同一資料夾內的項目, 再使用底部操作列的 `壓縮...`. 請選擇檔名、格式與壓縮等級; ZIP 與 7Z 可額外設定選用密碼.

目前版本可讀取與解壓縮 ZIP 系列、一般或 solid 7Z、RAR4/RAR5、TAR、TAR.GZ/TGZ、TAR.XZ/TXZ、TAR.BZ2/TBZ2 及 TAR.ZST/TZST, 並可建立一般或標準分割 ZIP、非 solid 7Z、TAR、TAR.GZ、TAR.XZ、TAR.BZ2 與 TAR.ZST; ZIP 與 7Z 可使用選用密碼, 加密輸出的檔名仍然可見. 一般單卷 ZIP、未加密且非 solid 並位於解碼資源預算內的一般單卷 7Z，以及符合條件的 TAR 系列壓縮檔可透過完整驗證重建加入、重新命名與刪除內容; RAR、加密、solid、分割、危險路徑、不支援方法或超出預算的 7Z 與 TAR 特殊項目維持唯讀. 完整的標準 `.z01 + .zip`、現代 `partN.rar`、編號 `.zip.001` 與編號 `.7z.001` 分割組可透過主程式有界核准的同層描述符瀏覽與解壓縮; 所有分割輸入均維持唯讀. 建立分割 ZIP 時可選擇預設或自訂 MiB 大小. 輸出超過所選大小時才會分割, 較小的輸出仍為單一 `.zip`.

所有實體輸出完成驗證與提交後, 一個預設關閉的選項可以把完整來源選取項目移入主程式垃圾桶. Explorer Action v21 保留有界持久復原記錄; 復原來源項目始終保留已建立的壓縮檔.

外掛程式不會要求廣泛的儲存空間或網路權限. 一般壓縮檔透過主程式唯讀描述符上的獨立位置讀取通道直接瀏覽, 無需複製整份內容; 不相容的輸入或後端（目前包括加密 ZIP）按需回退到私有快取, 並於關閉或過期後清理. 建立壓縮檔時會透過綁定外掛程式身份的短期主程式工作階段讀取目標, 並只能在目前上層資料夾以交易方式寫入輸出. 路徑穿越、來源檔案大小及輸出邊界檢查會始終保持啟用.
