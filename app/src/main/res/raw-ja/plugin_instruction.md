メインのファイルマネージャーから Archive Manager を使用します:

Archive Manager 2.22.0 には Android 7 以降と、Explorer Action v21 を公開する対応 AutoJs6 6.8.0 ビルド (versionCode 5276 以降) が必要です.

1. `Archive Manager` プラグインをインストールして有効にします.
2. 対応するアーカイブファイルのオーバーフローメニューを開きます.
3. `アーカイブを開く` を選択します.
4. フォルダーの参照、検索、パスバーでの移動、またはホストのビューアーによる対応項目の表示を行います.
5. 戻る操作は通常のファイル一覧へ戻る前に, アーカイブ内の上位フォルダーへ移動します.

アーカイブ全体を直接展開する場合は, ファイルメニューの `展開先...` を選び, 出力フォルダーを指定します.

アーカイブを作成するには, 通常のファイルまたはフォルダーのメニューで `圧縮...` を選びます. 同じフォルダーの複数項目を選択して下部バーの `圧縮...` を使うこともできます. ファイル名, 形式, 圧縮レベルを選択します. ZIP と 7Z には任意のパスワードも設定できます.

現在のバージョンは ZIP 系、通常または solid の 7Z、RAR4/RAR5、TAR、TAR.GZ/TGZ、TAR.XZ/TXZ、TAR.BZ2/TBZ2、TAR.ZST/TZST を読み取り・展開できます. 通常または標準分割 ZIP、非 solid 7Z、TAR、TAR.GZ、TAR.XZ、TAR.BZ2、TAR.ZST を作成でき, ZIP と 7Z には任意のパスワードを設定できますが, 暗号化出力のファイル名は表示されたままです. 通常の単一ボリューム ZIP、暗号化なし、非 solid、単一ボリュームかつデコーダー予算内の 7Z、対応する TAR 系アーカイブは完全検証付きの再構築による追加、名前変更、削除に対応します. RAR、暗号化、solid、分割、危険なパス、未対応方式、予算超過の 7Z と TAR の特殊項目は読み取り専用です. 完全な `.z01 + .zip`、`partN.rar`、`.zip.001`、`.7z.001` の各セットは、ホストが承認した有界の同階層ディスクリプターで参照・展開できますが、すべて読み取り専用です. 分割 ZIP 作成ではプリセットまたはカスタム MiB サイズを選べます. 出力が選択サイズを超える場合は分割され, 小さい場合は 1 個の `.zip` のままです.

すべての物理出力を検証して確定した後、既定で無効のオプションにより完全な元選択をホストのゴミ箱へ移動できます. Explorer Action v21 は有界で永続的な復元履歴を保持し、元項目を復元しても作成済みアーカイブは削除されません.

プラグインはストレージ全体やネットワークへの権限を要求しません. 通常のアーカイブはホストの読み取り専用ディスクリプター上の独立位置チャネルから全体コピーなしで直接参照します. 互換性のない入力または reader（現在は暗号化 ZIP を含む）だけをプライベートキャッシュへ退避し, 終了時または期限切れ後に削除します. アーカイブ作成はプラグインに固定された短期ホストセッションで読み取り, 現在の親フォルダーにのみトランザクション出力を書き込めます. パストラバーサル, 元ファイルのサイズ, 出力境界の検査は常に有効です.
