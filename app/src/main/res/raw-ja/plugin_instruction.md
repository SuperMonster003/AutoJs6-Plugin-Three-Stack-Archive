3-Stack Archive は AutoJs6 のファイルマネージャーにアーカイブ機能を追加します. ZIP, 7Z, RAR, TAR 系のアーカイブをフォルダーのように閲覧し, 全体または一部を展開でき, ファイルやフォルダーを圧縮することもできます. プラグインのホーム画面からも単独でアーカイブを開いて閲覧, 展開できます.

### はじめに

1. "プラグインセンター" で 3-Stack Archive を有効にします.
2. AutoJs6 のファイルマネージャーでアーカイブのメニューを開き, "アーカイブを表示" を選びます. 内容は同じファイル一覧に表示されます.
3. フォルダーを開く, 検索する, または項目をタップして AutoJs6 のプレビューアーで開きます. 戻るキーはまずアーカイブ内の一つ上の階層に戻ります.
4. ファイルを取り出すには, アーカイブのメニューから "展開先..." を選んで全体を展開するか, 項目を長押しして選択した部分だけを展開します.

### 主な機能

- **閲覧とプレビュー**: ZIP, JAR, 7Z, RAR, TAR 系のアーカイブを AutoJs6 のファイル一覧で閲覧し, 検索やパスバーでの移動ができます. 文書, 画像, 音声, 動画は展開せずにプレビューできます.
- **アーカイブとして開く**: ファイル名が認識されないときは, ファイルのメニューから "アーカイブとして開く..." を選びます. 形式は内容から判定され, パスバーに表示されます.
- **展開**: アーカイブ全体, 現在のフォルダー (パスバー右側のボタン), または選択した項目を展開でき, 進捗表示と取り消しに対応します. 同名のファイルはスキップ, 上書き, 自動の番号付けから選べます.
- **パスワードとファイル名の文字コード**: 暗号化された ZIP, 7Z, RAR は開くときや展開するときにパスワードを求め, 間違えてもすぐに再入力できます. ZIP のファイル名が文字化けしたときはパスバーで文字コードを切り替えます.
- **分割アーカイブ**: 揃った `.z01` + `.zip`, `partN.rar`, `.zip.001`, `.7z.001` の分割セットは閲覧, プレビュー, 展開ができますが, 変更はできません.
- **圧縮**: ファイル, フォルダー, または同じフォルダーで複数選択した項目に対して "圧縮..." を選び, ZIP, 7Z, TAR, TAR.GZ などを作成します. ZIP と 7Z はパスワードを設定でき, ZIP はサイズで分割できます.
- **項目ごとの圧縮**: 複数選択時に "各項目を個別に圧縮" をオンにすると, 項目ごとにアーカイブを作成します. 名前が重なる場合は自動で番号を付けます.
- **アーカイブの変更**: 通常の単一ボリュームの ZIP, 暗号化されていない非 solid の 7Z, TAR 系のアーカイブでは, ファイルやフォルダーの追加, 空フォルダーの作成, 項目の名前変更と削除ができます. 変更後は "以前のバージョンを復元" で一度だけ元に戻せます.
- **元の項目をゴミ箱へ**: 初期状態でオフの "圧縮後に元の項目をゴミ箱へ移動" をオンにすると, すべての出力の検証後にだけ元の項目を AutoJs6 のゴミ箱へ移動します. 圧縮画面のメニューの "元項目の復元履歴" から戻せます.
- **ホーム画面**: ランチャーからプラグインを開き, "圧縮ファイルを開く" をタップするとアーカイブを閲覧, 展開できます. "設定" では言語, ダークモード, テーマカラー, ランチャーアイコンを変更できます.

### スクリプトでの使い方

プラグインツール `archive_list`, `archive_read`, `archive_extract` を使うと, スクリプトからアーカイブの内容の一覧, 中のテキストファイルの読み取り, 展開ができます:

```js
let list = plugins.tools.call('archive_list', { archive: './demo.zip' });
list.result.entries.forEach(e => console.log(e.path, e.size));

let readme = plugins.tools.call('archive_read', { archive: './demo.zip', path: 'README.md' });
console.log(readme.result.text);

let extracted = plugins.tools.call('archive_extract', { archive: './demo.zip' }, {
    outputs: { files: './out/demo' },
});
console.log(extracted.result.filesExtracted, extracted.result.kept);
```

- 相対パスは AutoJs6 の作業ディレクトリを基準にします. 展開先のフォルダーは既に存在していてもよく, 既存のファイルはそのまま残り, 件数が `kept` に入ります.
- `archive_read` は UTF-8 テキストを 1 回につき最大 64 KiB 返します. バイナリファイルではテキストを返さず, `binary` が `true` になります.
- 暗号化されたアーカイブのパスワードは `password` で渡します. 分割アーカイブはプラグインツールでは扱えません.

### 動作要件

- Android 7.0 以降.
- AutoJs6 6.8.0 以降で, このプラグインが "プラグインセンター" で有効になっていること. プラグインのホーム画面は AutoJs6 がなくても使えます.
- ストレージやネットワークの権限は要求せず, AutoJs6 またはシステムのファイル選択画面で選んだファイルだけを扱います.

### よくある質問

**メニューにプラグインの操作が見つからない場合の対処**

このプラグインが "プラグインセンター" で有効になっているか確認してください. 一部の AutoJs6 のバージョンでは, プラグインの操作がプラグイン名のサブメニュー "3-Stack Archive" にまとめられています. 名前が認識されないアーカイブには "アーカイブとして開く..." を使います.

**アーカイブが閲覧のみで変更できない理由**

RAR, 分割アーカイブ, JAR/AAR/WAR, 暗号化または solid の 7Z は閲覧と展開のみです. "アーカイブを管理..." で現在のアーカイブの形式と読み取り専用の理由を確認できます.

**暗号化アーカイブ内のファイル名**

ZIP と 7Z の暗号化で保護されるのはファイルの内容で, アーカイブ内のファイル名は見えたままです. 機密情報はファイル名に含めないでください.

**分割アーカイブが開けない場合の対処**

標準の分割 ZIP は最後の `.zip` から, WinRAR のセットは最初の `partN.rar` から, 番号付きのセットは `.001` ファイルから開きます. すべてのボリュームを同じフォルダーに置く必要があります.

プラグインツールのすべての引数と戻り値は [AutoJs6 ドキュメント > プラグイン](https://docs.autojs6.com/#/plugins) を, その他の情報は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Stack-Archive) を参照してください.
