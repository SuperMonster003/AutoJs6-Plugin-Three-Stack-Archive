استخدم Archive Manager من مدير الملفات الرئيسي:

يتطلب Archive Manager 2.22.0 نظام Android 7 أو أحدث وبنية AutoJs6 6.8.0 متوافقة (versionCode 5276 أو أحدث) تعلن Explorer Action v21.

1. ثبت ملحق `Archive Manager` ومكنه.
2. افتح قائمة الخيارات لملف أرشيف مدعوم.
3. اختر `فتح الأرشيف`.
4. تصفح المجلدات أو ابحث أو استخدم شريط المسار أو افتح العناصر المدعومة بعارضات المضيف.
5. يعود زر الرجوع أولا إلى المجلد الأعلى داخل الأرشيف قبل الرجوع إلى قائمة الملفات العادية.

لاستخراج الأرشيف كاملا مباشرة, اختر `استخراج إلى...` من قائمة الملف ثم حدد مجلد الإخراج.

لإنشاء أرشيف, اختر `ضغط...` من قائمة ملف أو مجلد عادي. يمكنك أيضا تحديد عدة عناصر في المجلد نفسه واستخدام `ضغط...` في الشريط السفلي. اختر اسم الملف والتنسيق ومستوى الضغط; يمكن لـ ZIP و7Z استخدام كلمة مرور اختيارية أيضا.

يقرأ الإصدار الحالي أرشيفات عائلة ZIP و7Z العادية أو solid وRAR4/RAR5 وTAR وTAR.GZ/TGZ وTAR.XZ/TXZ وTAR.BZ2/TBZ2 وTAR.ZST/TZST ويستخرجها. وينشئ ZIP عاديا أو قياسيا مجزأ و7Z غير solid وTAR وTAR.GZ وTAR.XZ وTAR.BZ2 وTAR.ZST; يمكن لـ ZIP و7Z استخدام كلمة مرور اختيارية لكن أسماء الإخراج المشفر تبقى ظاهرة. تدعم ملفات ZIP العادية أحادية الجزء و7Z أحادية الجزء غير المشفرة وغير solid والواقعة ضمن ميزانية وحدة فك الترميز وأرشيفات TAR المؤهلة إضافة المحتوى وإعادة تسميته وحذفه عبر إعادة بناء كاملة التحقق. تبقى RAR وأنواع 7Z المشفرة أو solid أو المجزأة أو الخطرة أو غير المدعومة أو المتجاوزة للميزانية وعناصر TAR الخاصة للقراءة فقط. يمكن تصفح واستخراج المجموعات الكاملة `.z01 + .zip` و`partN.rar` و`.zip.001` و`.7z.001` عبر واصفات أشقاء محدودة يوافق عليها المضيف; وتبقى جميع مجموعات الأجزاء للقراءة فقط. يتيح إنشاء ZIP المجزأ حجما جاهزا أو مخصصا بوحدة MiB. يجزأ الناتج إذا تجاوز الحجم المحدد, أما الناتج الأصغر فيبقى ملف `.zip` واحدا.

بعد التحقق من كل المخرجات الفعلية وتثبيتها يمكن لخيار معطل افتراضيا نقل تحديد المصادر الكامل إلى سلة مهملات المضيف. يحتفظ Explorer Action v21 بسجل استرداد دائم ومحدود; ولا تؤدي استعادة المصادر أبدا إلى حذف الأرشيف المنشأ.

لا يطلب الملحق وصولا عاما إلى التخزين أو الشبكة. تتصفح الأرشيفات العادية عبر قنوات ذات موضع مستقل فوق واصف المضيف المخصص للقراءة فقط من دون نسخ الملف كاملا. وتعود المدخلات أو القارئات غير المتوافقة (وتشمل حاليا ZIP المشفر) إلى الذاكرة المؤقتة الخاصة التي تنظف عند الإغلاق أو انتهاء الصلاحية. تقرأ عملية إنشاء الأرشيف عبر جلسة مضيف قصيرة مرتبطة بالملحق ولا تكتب إلا إخراجا معاملاتيا في المجلد الأب الحالي. تظل فحوص اجتياز المسار وحجم المصدر وحدود الإخراج مفعلة دائما.
