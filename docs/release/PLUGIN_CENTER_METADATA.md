## Official index handoff

The official index is maintained in the separate `AutoJs6-Official-Plugins-Index` repository. After an authorized GitHub tag and release exist:

1. confirm the release asset exactly matches the locally verified APK receipt;
2. create `release-manifests/io.github.supermonster003.autojs6.plugin.archivemanager/28.json` in the index repository with the final source commit, signer, ABI list, asset size, and SHA-256;
3. run the index generator unit tests;
4. run `python tools/generate_official_plugin_index.py`;
5. inspect the generated Archive Manager entry and verify every localized URL is pinned to `refs/tags/v2.22.0`;
6. commit the index change separately.

No index-repository mutation or remote publication is authorized by this preparation document.
