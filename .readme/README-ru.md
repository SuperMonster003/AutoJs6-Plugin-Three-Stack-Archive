### О проекте

Archive Manager работает внутри файлового менеджера AutoJs6, а не заменяет его. Поддерживаемые архивы используют список, строку пути, тему, средства просмотра, выбор, прогресс и обновление каталогов хоста. Отдельная страница управления нужна только для расширенных настроек и операций записи.

### Доступно сейчас

- Просмотр ZIP/JAR/AAR/WAR, 7Z, RAR4/RAR5 и семейства TAR в штатном списке AutoJs6 с внутренним путем, поиском, сортировкой и навигацией Назад.
- Предпросмотр читаемых документов, изображений, аудио и видео существующими средствами хоста без предварительного извлечения всего архива.
- Извлечение всего архива, текущей внутренней папки или выбранных элементов с прогрессом, отменой, безопасными именами при конфликте, проверкой и откатом до публикации.
- Открытие и извлечение зашифрованных ZIP, 7Z и RAR со штатным запросом пароля; ошибочный пароль можно исправить без потери текущего пути.
- Исправление кодировки имен ZIP прямо в строке пути хоста; тот же сеанс только для чтения перестраивает индекс и по возможности сохраняет текущий внутренний путь и доступный выбор.
- Просмотр и извлечение полных стандартных наборов `.z01 + .zip` и современных наборов WinRAR `partN.rar` через ограниченные дескрипторы соседних томов, разрешенные хостом; отсутствующий или измененный том дает явную ошибку.
- Создание ZIP, 7Z, TAR, TAR.GZ, TAR.XZ, TAR.BZ2 и TAR.ZST из одного элемента или выбора с общим родителем; ZIP также поддерживает AES-256, стандартные тома и отдельный архив для каждого элемента.
- Редактирование обычного однотомного ZIP через проверенную пересборку: добавление файлов или дерева папок, создание пустых папок, переименование и удаление с атомарной заменой только после полного повторного чтения.
- Изоляция опасных имен в режиме только для чтения, структурные и ресурсные ограничения перед записью и прямое чтение seekable-дескриптора хоста, когда это возможно.

### Текущие форматы

Текущая версия распознаёт следующие расширения для просмотра и извлечения:

```text
zip, jar, aar, war, 7z, rar, tar, tar.gz, tgz, tar.xz, txz, tar.bz2, tbz2, tar.zst, tzst
```

Текущая версия может создавать следующие форматы:

```text
zip, 7z, tar, tar.gz, tar.xz, tar.bz2, tar.zst
```

> Для нативной интеграции требуется соответствующая сборка AutoJs6 6.8.0 с Explorer Action v13 (код версии 5276 или новее). RAR и многотомные архивы доступны только для чтения; редактирование ограничено обычными однотомными `.zip`. Стандартный разделенный ZIP открывайте через последний `.zip`, а современный набор WinRAR через первый `partN.rar`, разместив все обязательные тома в одной папке. `.zip.001`, разделенный 7Z, шифрование имен при создании, удаление источников и редактирование содержимого 7Z, RAR или TAR пока не поддерживаются.

### Использование

1. Установите Archive Manager и включите его в Центре плагинов AutoJs6.
2. Нажмите основное действие поддерживаемого файла или выберите Открыть архив, затем просматривайте его как обычную папку с помощью строки пути хоста.
3. Используйте действие извлечения в строке пути для текущей внутренней папки или действие кодировки для исправления имен ZIP, долгое нажатие для выбора элементов или Извлечь в... в меню файла для всего архива. При необходимости появится запрос пароля.
4. Выберите Сжать... для файла или папки либо отметьте несколько элементов одного каталога и используйте действие нижней панели.
5. Выбирайте Управление архивом... только для добавления, переименования или удаления содержимого обычного однотомного ZIP.

### Разрешения и данные

Archive Manager не запрашивает разрешения на хранилище или сеть. Хост передает краткоживущие дескрипторы только для чтения и транзакции, привязанные к UID плагина, поэтому произвольный путь выбрать нельзя. Explorer Action v11 передает пароль только в ограниченном синхронном запросе; обе стороны сразу очищают буферы и ничего не сохраняют. Explorer Action v12 добавляет только ограниченный каталог соседних томов, одобренных хостом и привязанных к сессии: плагин получает непрозрачные ID вместо путей, а UID вызывающей стороны, идентичность, размер, время изменения и срок жизни повторно проверяются. Explorer Action v13 повторно индексирует только тот же подготовленный источник, ограничивает список и имена кодировок и сохраняет прежнее состояние до готовности полного нового индекса. Из-за неизбежных копий времени выполнения очистка пароля остается максимально возможной. Опасные пути изолируются, вывод проверяется до публикации, а подтверждение бюджета не отключает структурную безопасность.

### Примечания к выпуску

#### v2.6.0

_2026/08/27_

- `Примечание` Для этой версии требуется соответствующая сборка AutoJs6 6.8.0 с Explorer Action v13 (код версии 5276 или новее)
- `Добавлено` На нативной странице архива теперь можно выбрать кодировку имен ZIP в строке пути без перехода на страницу управления; после смены сохраняются текущая внутренняя папка и существующие выбранные элементы
- `Добавлено` Explorer Action v13 повторно индексирует подготовленный источник в том же сеансе только для чтения и использует стабильные ID для восстановления самого глубокого доступного пути и существующих элементов
- `Улучшено` Новый индекс публикуется только после полной готовности; неверный выбор, ошибка сканирования, активный просмотр или извлечение сохраняют прежний индекс, а введенный пароль остается только в очищаемой памяти

#### v2.5.0

_2026/08/27_

- `Примечание` Для этой версии требуется соответствующая сборка AutoJs6 6.8.0 с Explorer Action v12 (код версии 5276 или новее)
- `Добавлено` Полные стандартные наборы `.z01 + .zip` и современные наборы WinRAR `partN.rar` теперь можно просматривать и извлекать на нативной странице; многотомные архивы остаются только для чтения
- `Добавлено` Explorer Action v12 передает только ограниченный каталог соседних томов, одобренных хостом, и открывает каждый по непрозрачному ID как дескриптор только для чтения, не раскрывая каталог или системный путь
- `Исправлено` Метаданные каталога последнего тома разделенного ZIP корректно принимаются на Android 7 и новее, а данные читаются из всех разрешенных томов без ложного сообщения о повреждении последнего тома
- `Исправлено` CRC сегмента RAR больше не сравнивается с восстановленными данными; отсутствующие или изменившиеся после открытия тома дают стабильные типизированные ошибки
- `Улучшено` Количество, имена, ID и число открытий томов, UID вызывающей стороны, идентичность файлов и срок жизни сессии ограничены и повторно проверяются; прерванное копирование удаляет все фрагменты приватного кэша

#### v2.4.0

_2026/08/26_

- `Примечание` Для этой версии требуется AutoJs6 6.8.0 с Explorer Action v11, код версии 5276 или новее
- `Добавлено` Архивы RAR4/RAR5 теперь можно просматривать, предварительно открывать и извлекать, включая шифрование содержимого и заголовков; RAR намеренно остается только для чтения
- `Добавлено` Нативная страница архива AutoJs6 может запросить пароль при первом открытии или во время извлечения и повторить операцию без потери пути или выбора
- `Исправлено` Первый том разделенного RAR сохраняет читаемые метаданные, но больше не предлагает извлечение, если соседние тома недоступны
- `Исправлено` После неверного пароля прежний ввод очищается, а повтор выполняется для неизмененного снимка без выхода из нативной страницы
- `Улучшено` RAR по возможности читает seekable-дескриптор хоста напрямую, не добавляет нативных ABI и использует общие проверки безопасности
- `Зависимость` Добавлены Junrar 8.1.0 и SLF4J 2.0.17 для RAR только для чтения на условиях вложенных лицензий
