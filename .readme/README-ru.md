### О проекте

Archive Manager работает внутри файлового менеджера AutoJs6, а не заменяет его. Поддерживаемые архивы используют список, строку пути, тему, средства просмотра, выбор, прогресс и обновление каталогов хоста. Отдельная страница управления нужна только для расширенных настроек и операций записи.

### Доступно сейчас

- Просмотр ZIP/JAR/AAR/WAR, 7Z, RAR4/RAR5 и семейства TAR в штатном списке AutoJs6 с внутренним путем, поиском, сортировкой и навигацией Назад.
- Предпросмотр читаемых документов, изображений, аудио и видео существующими средствами хоста без предварительного извлечения всего архива.
- Извлечение всего архива, текущей внутренней папки или выбранных элементов с прогрессом, отменой, безопасными именами при конфликте, проверкой и откатом до публикации.
- Открытие и извлечение зашифрованных ZIP, 7Z и RAR со штатным запросом пароля; ошибочный пароль можно исправить без потери текущего пути.
- Создание ZIP, 7Z, TAR, TAR.GZ, TAR.XZ, TAR.BZ2 и TAR.ZST из одного элемента или выбора с общим родителем; ZIP также поддерживает AES-256, стандартные тома и отдельный архив для каждого элемента.
- Редактирование обычного однотомного ZIP через проверенную пересборку: добавление файлов или дерева папок, создание пустых папок, переименование и удаление с атомарной заменой только после полного повторного чтения.
- Изоляция опасных имен в режиме только для чтения, структурные и ресурсные ограничения перед записью и прямое чтение seekable-дескриптора хоста, когда это возможно.

### Текущие форматы

Текущая версия распознаёт следующие расширения для просмотра и извлечения:

```text
zip, jar, aar, war, 7z, rar, tar, tar.gz, tgz, tar.xz, txz, tar.bz2, tbz2, tar.zst, tzst
```

Текущая версия может создавать следующие форматы:

```text
zip, 7z, tar, tar.gz, tar.xz, tar.bz2, tar.zst
```

> Для нативной интеграции требуется AutoJs6 6.8.0 с кодом версии 5276 или новее и Explorer Action v11. RAR намеренно доступен только для чтения. Редактирование ограничено обычными однотомными `.zip`. Существующие наборы разделенных ZIP/RAR пока нельзя прочитать целиком, потому что хост предоставляет только дескриптор выбранного файла; первый том RAR может показать метаданные, но извлечение отключено. Шифрование имен при создании, удаление источников после сжатия и редактирование содержимого 7Z, RAR или TAR пока не поддерживаются.

### Использование

1. Установите Archive Manager и включите его в Центре плагинов AutoJs6.
2. Нажмите основное действие поддерживаемого файла или выберите Открыть архив, затем просматривайте его как обычную папку с помощью строки пути хоста.
3. Используйте действие в строке пути для текущей внутренней папки, долгое нажатие для выбора элементов или Извлечь в... в меню файла для всего архива. При необходимости появится запрос пароля.
4. Выберите Сжать... для файла или папки либо отметьте несколько элементов одного каталога и используйте действие нижней панели.
5. Выбирайте Управление архивом... только для добавления, переименования или удаления содержимого обычного однотомного ZIP.

### Разрешения и данные

Archive Manager не запрашивает разрешения на хранилище или сеть. Хост передает краткоживущий дескриптор только для чтения и транзакции вывода, привязанные к UID плагина, поэтому плагин не может выбрать произвольный путь. Explorer Action v11 передает пароль только в ограниченном синхронном запросе повтора; хост и плагин сразу удаляют и очищают удерживаемые буферы и не сохраняют пароль в состоянии, настройках, журналах или диагностике. Android и библиотеки Java все же могут создавать неизбежные краткоживущие копии во время выполнения, поэтому это максимально возможная очистка памяти, а не абсолютная гарантия. Опасные пути изолируются, вывод проверяется до публикации, а подтверждение ресурсного бюджета не отключает структурную безопасность.

### Примечания к выпуску

#### v2.4.0

_2026/08/26_

- `Примечание` Для этой версии требуется AutoJs6 6.8.0 с Explorer Action v11, код версии 5276 или новее
- `Добавлено` Архивы RAR4/RAR5 теперь можно просматривать, предварительно открывать и извлекать, включая шифрование содержимого и заголовков; RAR намеренно остается только для чтения
- `Добавлено` Нативная страница архива AutoJs6 может запросить пароль при первом открытии или во время извлечения и повторить операцию без потери пути или выбора
- `Исправлено` Первый том разделенного RAR сохраняет читаемые метаданные, но больше не предлагает извлечение, если соседние тома недоступны
- `Исправлено` После неверного пароля прежний ввод очищается, а повтор выполняется для неизмененного снимка без выхода из нативной страницы
- `Улучшено` RAR по возможности читает seekable-дескриптор хоста напрямую, не добавляет нативных ABI и использует общие проверки безопасности
- `Зависимость` Добавлены Junrar 8.1.0 и SLF4J 2.0.17 для RAR только для чтения на условиях вложенных лицензий

#### v2.3.0

_2026/08/26_

- `Примечание` Для этой версии требуется совместимая сборка AutoJs6 6.8.0 с Explorer Action v10 (код версии 5276 или новее)
- `Добавлено` Нативная страница архива теперь извлекает текущую внутреннюю папку из строки пути или отмеченные элементы из панели выбора без открытия отдельной страницы управления
- `Добавлено` Нативное извлечение пишет в дерево вывода, принадлежащее хосту, показывает ход задачи, поддерживает отмену, безопасную нумерацию конфликтов и автоматическое обновление Explorer
- `Исправлено` Выход из архива на Android 7 больше не вызывает сбой во время очистки кэша предпросмотра хостом
- `Исправлено` Подписи на панели выбора с пятью действиями центрируются под значками на узких экранах
- `Улучшено` Режим выбора в архиве теперь показывает только Выход и Извлечь, скрывая операции файловой системы, неприменимые внутри архива

#### v2.2.0

_2026/08/26_

- `Примечание` Для этого выпуска требуется соответствующая сборка AutoJs6 6.8.0 с Explorer Action v9 (код версии 5276 или новее)
- `Добавлено` Команда «Извлечь в...» теперь рекомендует текущую папку и создаёт одноимённую выходную папку через принадлежащую хосту транзакцию каталога; эквивалентное существующее имя безопасно нумеруется без изменения его содержимого
- `Добавлено` Управление обычным однотомным ZIP может импортировать целую папку через системный выбор Android, включая вложенные файлы и пустые папки
- `Исправлено` Выбор папки извлечения остаётся полностью доступным на узких и низких экранах и показывает точный путь по умолчанию
- `Исправлено` Отменённое, неудачное, прерванное или исчерпавшее место извлечение в ту же папку откатывает неопубликованный вывод; следующий сеанс восстанавливает прерванные транзакции хоста без изменения исходного архива
- `Улучшено` Explorer Action v9 атомарно публикует проверенные деревья каталогов и сразу после фиксации обновляет новую выходную папку в AutoJs6
